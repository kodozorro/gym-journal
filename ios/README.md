# Приложения на Swift: iPhone и Apple Watch

Те же экраны и та же таблица, что у веб-приложения, и то, чего сайт на iPhone не умеет:
тренировка в «Здоровье», приложение на часах, вибрация и уведомление в конце отдыха.

Как поставить приложения на свой iPhone и часы: [docs/ios.md](../docs/ios.md).

## Как устроено

```
Apple Watch ── действия ──► iPhone ── POST, JSON, ключ в теле ──► Apps Script ──► лист «Журнал»
Apple Watch ◄── состояние дня ── iPhone
```

- Скрипт в таблице тот же, что у веб-приложения, и формат обмена тот же. Таблица остаётся
  единственным хранилищем: приложение пишет только в ячейки ввода листа «Журнал».
- В таблицу пишет только телефон. Часы получают от него состояние дня и возвращают действия:
  подход, вес, отрезок ходьбы, отдых, начало и конец тренировки.
- Адрес скрипта и ключ вводятся в настройках и хранятся в связке ключей телефона. На часы они
  не попадают.
- План тренировок берётся из таблицы. В коде есть только справочник для кнопки «i»: фото
  тренажёра, рисунок и подсказки.

| Папка | Что в ней |
|---|---|
| `Core/` | Пакет `GymJournalCore`: логика без интерфейса, общая для телефона и часов. Даты, числа, журнал, план, очередь записей, синхронизация, справочник, обмен с часами |
| `App/` | Приложение для iPhone на SwiftUI: экраны, модель, «Здоровье», уведомления, связь с часами |
| `Watch/` | Приложение для Apple Watch: список дня, упражнение, отдых, ходьба, тренировка |
| `Config/` | Настройки сборки. Команда разработчика лежит в `Local.xcconfig`, в репозиторий он не попадает |
| `tools/` | Скрипты Node.js: переносят рисунки, значки и учебные данные из веб-приложения |
| `project.yml` | Описание проекта для XcodeGen. Самого проекта Xcode в репозитории нет |

## Собрать и запустить

Нужны Mac с Xcode 26 и [XcodeGen](https://github.com/yonaskolb/XcodeGen) 2.38 или новее.
Приложения работают на iOS 17 и watchOS 10 и новее. Собраны и проверены в Xcode 26.6. Часы с
watchOS 27 подключаются к Mac только из Xcode 27 (см. [docs/ios.md](../docs/ios.md)); в нём
проект пока не собирали.

```bash
cd ios
xcodegen generate            # делает GymJournal.xcodeproj из project.yml
open GymJournal.xcodeproj
```

В Xcode две схемы: `GymJournal` (iPhone, приложение для часов едет внутри него) и
`GymJournalWatch` (только часы). Для симулятора подпись не нужна. Для своих устройств скопируйте
`Config/Local.xcconfig.example` в `Config/Local.xcconfig` и впишите команду разработчика.

После правки `project.yml` или появления новых файлов запустите `xcodegen generate` заново.

## Тесты

```bash
cd ios/Core && swift test    # логика: сверяется с веб-приложением по эталонам
npm test                     # из корня: данные для Swift, цвета, права, значки
```

Тесты пакета `Core` читают эталоны из `Core/Tests/GymJournalCoreTests/Fixtures`: это ответы
настоящей логики веб-приложения и настоящего `Code.gs` на учебной таблице. Так перенос на Swift
не расходится с сайтом.

## Данные из веб-приложения

Рисунки упражнений, значки, учебный журнал и эталоны для тестов не пишутся руками, а
делаются из кода сайта:

```bash
npm run ios:data             # после правки js/core, js/ui/art.js, js/ui/icons.js, Code.gs, tools/fixture.mjs
node ios/tools/icon.mjs      # значки приложений из icons/icon.svg, нужен Playwright
```

Тест `tests/ios.test.mjs` упадёт, если данные отстали от кода. Фотографии тренажёров общие с
сайтом: папка `img/machines` целиком попадает в приложение для iPhone.

## Показ с учебными данными

Оба приложения умеют запускаться с выдуманным журналом, без таблицы, «Здоровья» и связи друг с
другом. Это нужно для снимков экрана и проверки в симуляторе.

```bash
xcrun simctl launch booted io.github.kodozorro.gymjournal -demo YES -demoToday 2026-11-25 -demoScene round
xcrun simctl launch booted io.github.kodozorro.gymjournal.watchkitapp -demo YES -demoToday 2026-11-25 -demoScene exercise
```

- Сцены телефона: `today`, `round`, `weight`, `note`, `info`, `walk`, `offline`, `day`, `workout`,
  `sync`, `plan`, `progress`, `settings`, `connect`, `welcome`.
- Сцены часов: `today`, `exercise`, `rest`, `sets`, `list`, `weight`, `walk`, `segment`, `workout`,
  `live`, `connect`, `first`.
- Чтобы проверить обмен на паре симуляторов, телефон запускают с `-demo YES -demoDevices YES`:
  журнал учебный, а связь с часами и «Здоровье» настоящие. Часы при этом запускают без `-demo`,
  только с `-demoToday`: так «сегодня» у них совпадает с учебным журналом.

## Телефон и часы

Обмен описан в `Core/Sources/GymJournalCore/WatchLink.swift` и покрыт тестами.

- Телефон присылает состояние дня целиком: строки, «прошлый раз», шаг веса, отдых, тренировку.
  У каждого состояния номер, более старое часы не принимают.
- Часы возвращают действия по одному, каждое со своим номером. Телефон применяет действие один
  раз, сколько бы раз оно ни пришло, и в следующем состоянии называет номер последнего принятого.
- Пока подтверждения нет, часы показывают свои действия поверх присланного состояния. Поэтому
  записывать можно и без связи: действия дойдут, когда телефон появится.
- Запись с часов будит свёрнутое приложение на телефоне, и оно отправляет её в таблицу.

## Тренировка в «Здоровье»

- Тренировку начинают кнопкой на экране дня на телефоне или на часах: силовую, если в дне
  есть тренажёры, и ходьбу, если есть ходьба.
- Настоящую тренировку с пульсом и калориями ведут часы (`Watch/Sources/Platform/WorkoutManager.swift`).
  Телефон просит часы начать её и открывает приложение на них сам.
- Если часов нет или они не ответили за 15 секунд, телефон записывает в «Здоровье» вид
  тренировки и её время. Пульс и калории он не выдумывает.
- После ходьбы часы предлагают записать отрезок: минуты посчитаны, километры взяты с датчиков.
  На дорожке число на её табло точнее, поэтому перед записью его можно поправить.

## Сигнал конца отдыха

- iPhone: звук и вибрация в приложении, а когда телефон заблокирован — уведомление с тем же
  звуком. Звук и вибрация выключаются в настройках по отдельности.
- Часы вибрируют сами, пока приложение на экране или идёт тренировка. С опущенной рукой и без
  тренировки о конце отдыха напоминает уведомление. Вибрация часов выключается в настройках на
  телефоне. Отдельного звука у часов нет: его добавляет к вибрации сама система, когда на часах
  выключен бесшумный режим.
